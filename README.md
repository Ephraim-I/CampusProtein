# CampusProtein

A Nigeria-first alternative-protein marketplace for Veritas University students.

## Features
- Smart marketplace with Nigerian alternative proteins
- Budget-based Protein Finder
- Cart, ordering, order tracking  
- Meal logging & nutrition tracking
- Gamification: points, streaks, badges, challenges
- AI Assistant with Nigerian protein knowledge
- Vendor and admin portals

## Tech: FastAPI + React + SQLite
